# Insper Mind - Frontend

Frontend do projeto final de Arquitetura de Objetos (Insper).

## Deploy

- **Frontend**: https://project-n6wej.vercel.app/
- **Backend**: http://3.237.223.11:8080/
- **Swagger**: http://3.237.223.11:8080/swagger-ui/index.html

## Sobre

Plataforma de compartilhamento de materiais e gerenciamento de informações acadêmicas. O projeto contempla:

- Autenticação de usuários com JWT
- Painel de cursos e disciplinas
- Compartilhamento de materiais educacionais
- Sistema de comentários e favoritos
- Painel administrativo

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- SWR para data fetching

## Instalação Local

```bash
pnpm install
pnpm dev
```

Acesse `http://localhost:3000`

## Build para Produção

```bash
pnpm build
pnpm start
```
npm run dev
```
